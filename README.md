# Karika — Landing

Landing de Karika, marca de dermocosmética con distribución en México.

Reglas de trabajo y estructura del proyecto: [`CLAUDE.md`](./CLAUDE.md).
Brief de negocio, diseño y contenido: [`docs/brief.md`](./docs/brief.md).

## Comandos

Todos se corren desde la raíz del proyecto:

| Comando                | Acción                                           |
| :---------------------- | :------------------------------------------------ |
| `npm install`           | Instala las dependencias                          |
| `npm run dev`           | Levanta el servidor local en `localhost:4321`     |
| `npm run build`         | Genera el sitio estático en `./dist/`             |
| `npm run preview`       | Previsualiza el build antes de desplegar          |
| `npm run lint`          | Corre ESLint                                      |
| `npm run format`        | Formatea el código con Prettier                   |
| `npm run format:check`  | Verifica el formato sin escribir cambios          |
